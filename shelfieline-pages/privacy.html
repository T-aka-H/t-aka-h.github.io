Shelfieline — プライバシーポリシー

最終更新: 2026-08-01 (v1.1)

本ポリシーは、Shelfieline (以下「本アプリ」) が本アプリがユーザー情報をどのように扱うかを説明します。

1. データ収集

本アプリは、ユーザーの個人データを収集しません。蔵書情報・読書ステータス・読書日記・表紙画像など、作成した内容はすべて iOS 標準の SwiftData によって お使いの端末内にのみ 保存され、端末外に出ることはありません。開発者のサーバーに送られるのは、第2節に記載する匿名の利用統計だけです。

2. 匿名の利用統計

アプリ改善のため、開発者が運用するサーバー (Cloudflare 上の collect.appline.app) に 匿名の利用回数 を送信します。数えているのは、アプリの起動回数、本が追加された回数 (うちバーコード経由の回数)、棚が作られた回数、読書メモが作られた回数、共有機能からの取り込み回数、テーマ・壁紙が変更された回数、Pro 画面の表示・購入・復元の回数で、いずれも 合計値のみ です。

送信するもの (これだけ): あらかじめ決められた固定のイベント名と、アプリのバージョン番号のみです。

送信しないもの: 氏名・メールアドレス・アカウント情報・端末識別子 (IDFA / IDFV)・広告ID・位置情報は送信しません。書名・著者・ISBN・読書メモの本文・表紙画像も一切送信しません。

個人の識別・追跡はできません: 本アプリは端末やユーザーに 永続的な識別子を一切割り当てません (端末ID・セッションIDなし)。保存されるのは「何回起きたかの合計」だけで、それらを結び付ける鍵が存在しないため、特定の利用者を識別すること・同一人物を追跡すること・プロファイルを作ることは構造上不可能です。

送信先: 開発者自身のサーバーのみです。Google・Firebase・Meta などの第三者に渡すことはありません。IPアドレスは記録・保存・利用しません。

3. アカウント登録

本アプリはアカウント登録機能を持ちません。メールアドレス・電話番号・氏名などの登録は不要です。

4. ユーザートラッキング

本アプリは Google Analytics や Facebook SDK 等の 第三者 アナリティクス・トラッキング SDK を組み込んでいません。広告も表示しません。第2節の匿名カウントは開発者自身のサーバーにのみ送られ、誰の identity とも結び付いていないため ATT でいう「トラッキング」には該当せず、ATT のリクエストも行いません。

5. 外部 API への通信

書誌情報 (タイトル・著者・出版社など) を取得するため、ユーザーがバーコードスキャン等で本を追加した際に、以下の公式 API へ ISBN を送信します:

  • openBD (https://openbd.jp/) — 書誌情報の自動取得
  • 国立国会図書館サーチ (https://ndlsearch.ndl.go.jp/) — 書誌情報の補完

これらのリクエストには ISBN 番号のみが含まれ、ユーザー識別子・端末識別子などの個人情報は一切送信されません。

6. カメラ・写真ライブラリの使用

本アプリは以下の用途で iOS のカメラ・写真ライブラリへのアクセスを求めます:

  • カメラ: 本のバーコード読み取り (Vision フレームワーク)、本の表紙をユーザー自身で撮影する用途
  • 写真ライブラリ: ユーザーが既に撮影/保存している表紙画像を本に紐付ける用途

取得された画像はすべて端末内 (SwiftData の external storage) にのみ保存され、外部へ送信されることはありません。

7. Share Extension

本アプリには Share Extension (BookshelflineShare) が含まれます。Safari など他アプリから「画像」または「URL」を共有した際、共有データは App Group 経由でメインアプリの inbox に一時保存され、ユーザーが本に紐付けるまで保持されます。inbox の内容は端末内のみで、外部へ送信されません。

8. データの削除

本アプリで作成したすべてのデータは、本アプリを iPhone / iPad からアンインストールすることで完全に削除されます。開発者がデータを保持することはありません。

9. 子どもの利用

本アプリは全年齢 (4+) 対象です。13 歳未満の子どもからの個人データを意図的に収集することはありません。

10. ポリシーの変更

本ポリシーは予告なく改訂される場合があります。重要な変更がある場合は、本ページに改訂日を記載してお知らせします。

11. お問い合わせ

本ポリシーに関するご質問は trim.hoist.6b@icloud.com までお寄せください。

Shelfieline — Privacy Policy

Last updated: 2026-08-01 (v1.1)

This Privacy Policy explains how Shelfieline ("the App") handles user information.

1. Data Collection

The App collects no personal data. Everything you create — library entries, reading status, reading notes, and cover images — is stored solely on your device using Apple's SwiftData framework and never leaves it. The only thing sent to the developer's server is the anonymous usage statistics described in section 2.

2. Anonymous Usage Statistics

To improve the App, it sends anonymous usage counts to a server operated by the developer (collect.appline.app, on Cloudflare). What is counted, all as totals (aggregates) only: how many times the app is opened, a book is added (and how many of those came from a barcode scan), a shelf is created, a reading note is written, a share import is consumed, a theme or wallpaper is changed, and the Pro screen is shown, purchased, or restored.

What is sent (only this): a fixed, predefined event name plus the app version number. Nothing else.

What is never sent: no name, email, account information, device identifier (IDFA / IDFV), advertising ID, or location — and never a book title, author, ISBN, reading-note text, or cover image.

No individual can be identified or tracked: the App assigns no persistent identifier to a device or user (no device ID, no session ID). All that is stored is "how many times, in total, something happened" — there is no key to join these counts on, which makes it structurally impossible to identify a reader, follow the same person over time, or build a profile.

Where it goes: only to the developer's own server. It is never shared with any third party such as Google, Firebase, or Meta. Your IP address is not logged, stored, or used.

3. Account Registration

The App has no account registration feature. No email address, phone number, or personal identifiers are required.

4. User Tracking

The App contains no third-party analytics or tracking SDKs (no Google Analytics, no Facebook SDK, etc.). No advertisements are shown. The anonymous counts in section 2 go only to the developer's own server and are not linked to anyone's identity, so they do not constitute tracking under App Tracking Transparency (ATT); the App does not present an ATT prompt.

5. External API Communication

When you add a book via barcode scan or ISBN entry, the App queries the following official APIs by sending only the ISBN number:

  • openBD (https://openbd.jp/) — bibliographic information lookup
  • National Diet Library Search (https://ndlsearch.ndl.go.jp/) — bibliographic supplementation

These requests contain only the ISBN. No user identifiers, device identifiers, or any other personal information are sent.

6. Camera and Photo Library Use

The App requests access to the iOS camera and photo library for the following purposes:

  • Camera: reading book barcodes (via the Vision framework), and letting the user capture a book cover photo themselves.
  • Photo Library: letting the user attach an existing photo from their library to a book as a cover image.

All captured images are stored only on your device (in SwiftData's external storage) and are never transmitted externally.

7. Share Extension

The App includes a Share Extension (BookshelflineShare). When you share an image or URL from another app such as Safari, the shared data is temporarily stored in the main app's inbox via App Group and held until you assign it to a book. The inbox content stays on the device and is not transmitted externally.

8. Data Deletion

All data created by the App is completely removed when you uninstall the App from your iPhone or iPad. The Developer retains no data.

9. Children's Use

The App is rated for all ages (4+). It does not knowingly collect personal data from children under 13.

10. Changes to This Policy

This Policy may be updated without prior notice. Material changes will be indicated by updating the date at the top of this page.

11. Contact
