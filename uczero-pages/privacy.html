UnderCover Zero — プライバシーポリシー

ホーム サポート プライバシー

最終更新: 2026年8月14日

本ポリシーは、UnderCover Zero（以下「本アプリ」）における情報の取り扱いを説明します。本アプリは、ゲームの進行に必要な最小限の情報だけを、一緒に遊んでいる相手とだけ、遊んでいる間だけ共有します。

1. 収集する情報

本アプリは個人を特定する情報を収集・保存しません。アカウント登録は不要で、氏名・メールアドレス・電話番号・SNS アカウントのいずれも登録も収集もしません。第三者の分析（アナリティクス）や広告の SDK も含まれていません。アプリの改善のために匿名の利用回数だけを記録していますが、個人を識別する情報は含みません（第6節）。

2. ゲーム中に共有される情報

ゲームが有効な間、次の情報が一緒に遊んでいる相手とのみ共有されます。

  • おおまかな位置: 実際の座標ではなく、約100メートル四方の区画に丸めた位置。距離と方角の目安にのみ使用します
  • 端末の向き: レーダーを正しい方向に向けるための方位
  • 使い捨ての近接測位トークン: 端末どうしが直接距離を測るための識別子。ゲームごとに新しく作られ、他の用途には使えません

共有は常に双方向です。片方だけが相手の位置を送る状態にはなりません。ゲームの役割によって画面の表示は変わり、探す側にはレーダーと距離が、かくれる側には近さの警告だけが表示されますが、データのやり取り自体は対等です。共有はアプリを開いている間だけ行われ、バックグラウンドでの位置取得や追跡は行いません。

3. 端末内での処理

近距離での正確な距離と方向は、端末どうしが直接やり取りして計算します。この情報が外部のサーバーへ送られることはありません。カメラは方向表示の精度を上げるためだけに使用し、映像の保存も送信も行いません。Bluetooth は相手との近さの検知にのみ使用します。気圧センサーの情報は、相手とのフロアの違い（上下の差）を検知するために相手とのみ暗号化して交換し、サーバーには保存されません。

4. サーバーでの取り扱い

セクション2の情報は、ゲームを成立させるために当方のサーバー（uczero.appline.app、Cloudflare 上）を経由します。

  • 保存するのは丸めた位置・方位・使い捨てトークン・進行状態のみで、個人を特定できる情報は含みません
  • ゲームが終わったとき、どちらかが終了したときは即座に削除されます
  • そのいずれも起きなかった場合も、リンクの発行から3時間で自動的に消滅します
  • アクセスログや IP アドレスの記録は行いません

プレイの履歴がサーバーに残ることはありません。端末側については第7節をご覧ください。

5. 端末の権限

  • 位置情報（使用中のみ）: 相手との距離と方角を表示するため
  • 近くのデバイスとの通信: 相手との正確な距離と方向を測るため
  • Bluetooth: 相手との接近を検知するため
  • モーション（気圧センサー）: 相手とのフロアの違いを検知するため
  • カメラ: 方向表示の精度を上げるため（映像は保存・送信しません）

いずれもゲーム画面を開いている間のみ使用します。

6. 匿名の利用統計

アプリの改善のために、操作の合計回数だけを記録しています。送信するのは「アプリ名」「操作の名前」「アプリのバージョン」の 3 つだけです。

  • 記録するのは「アプリが起動された」「リンクが作られた」「相手がリンクを開いた」「精密な測位に入った」「見つかった」「見つからずに終わった」の合計回数です
  • 端末やユーザーを識別する情報を一切持ちません。アカウント ID も端末 ID も広告 ID も、独自の識別子も付けていません。結び付ける鍵が無いため、「誰が」「いつ」「どこで」はデータとして存在しません。個人の行動履歴やプロファイルを作ることは構造的にできません
  • 位置情報・自由入力の文字列・戦績の中身は送信しません
  • 送信先は当方の Cloudflare サーバー（collect.appline.app）のみです。第三者の分析サービスや広告会社に渡すことはありません
  • サーバー側はあらかじめ決めた操作名しか受け付けません。それ以外は記録せずに捨てます
  • IP アドレスの記録・保存・利用は行いません

7. 戦績（この端末の中だけ）

ゲームの結果を手元に残せます。残るのはこの端末の中だけです。

  • 残るのは、遊んだ日時・勝敗・自分の役割・かかった時間・最も離れていた距離です
  • 位置そのものは記録しません。どこで遊んだかは戦績から分かりません
  • 相手が誰であるかは本アプリには分かりません。呼び名を付ける場合はご自身で入力いただくもので、相手の情報を取得することはありません
  • 保存先はこの端末の中だけです。サーバーにも iCloud にも送信されず、端末のバックアップからも除外されます
  • 一覧画面からいつでも 1 件ずつ、またはまとめて削除できます

8. Apple Watch

Apple Watch では、iPhone が表示している内容をそのまま映しているだけです。Watch が独自に位置を取得したり通信したりすることはなく、iPhone から Watch へ渡すのは距離・向き・進行状態だけで、位置そのものは渡していません。

9. 子どものプライバシー

本アプリは子ども向けに設計されていません。児童から意図的に情報を収集することはありません。

10. 改定について

本ポリシーを変更する場合は、本ページの最終更新日を改めて掲載します。
