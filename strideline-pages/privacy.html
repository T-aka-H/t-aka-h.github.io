Strideline — プライバシーポリシー

最終更新: 2026-07-12 (v1.1)

v1.1 での変更: アプリ改善のため、匿名の操作カウントの送信を追加しました (下記セクション2)。数えるのは「アプリが起動された回数」「どの機能が使われたか」「有料版 (Strideline Pro) の案内・購入の回数」で、いずれも匿名の合計値です。識別子を一切持たないため、特定のお子さまを識別したり、個人を時系列で追跡したり、プロファイルを作ることはできません。氏名・メールアドレス・端末識別子・位置情報・学習内容は一切含みません。変更点を隠さずお知らせするため、本セクションを記載しています。

Strideline (以下「本アプリ」) がユーザー情報をどのように扱うかを説明します。

1. データ収集

学習スケジュール・予定ブロック・実測セッション・カウントダウン・教材ライブラリなど、あなたの学習に関するデータおよび個人データは、すべて iOS 標準の SwiftData によってお使いの端末内にのみ保存され、開発者のサーバーには送信されません。端末外へ送信されるのは、セクション2で説明する匿名の利用統計 (個人と結び付かない操作カウント) のみです。

2. 匿名の利用統計

本アプリをよりよくするため、匿名の操作カウントを開発者自身のサーバー (collect.appline.app) に送信します。数えるのは次の3種類で、いずれも合計値 (集計) のみです:

  • アプリが起動された回数 (どれくらい使われているかの目安)
  • どの機能・画面が使われたか (例: カレンダー・統計・カウントダウンを開いた、学習タイマーを開始した、教材を追加した、カレンダーから取り込んだ — 使われていない機能を見つけて改善するため)
  • 有料版 (Strideline Pro) の案内・購入まわりの操作 (例: Pro画面が表示された、購入ボタンが押された、購入が完了した、復元した)

送信する内容 (これだけです): あらかじめ決められた固定のイベント名 + アプリのバージョン番号 (例: 1.1) のみ。

送信しないもの: 氏名・メールアドレス・アカウント情報・端末識別子 (IDFA / IDFV など)・広告 ID・位置情報・学習内容・その他あらゆる個人を特定できる情報。これらは一切送信しません。

個人・お子さまを特定・追跡することはできません: 本アプリは端末やお子さまに永続的な識別子を一切割り当てません (端末 ID やセッション ID を持ちません)。そのため送られるのは「ある操作が合計で何回起きたか」だけで、それらを結び付ける手がかりが存在せず、特定のユーザーやお子さまを識別したり、同一人物を時系列で追いかけたり、プロファイルを作ったりすることは構造的に不可能です。「何人が使ったか (アクティブユーザー数)」や継続率のような個人単位の統計も、この仕組みでは取得できません (それらは Apple の App Store Connect が集計する匿名データからのみ把握します)。

送信先: 開発者自身が管理するサーバー (Cloudflare 上) のみです。Google・Firebase・Meta などの第三者には一切渡しません。通信はネットワーク上、開発者のサーバー基盤 (Cloudflare) を経由しますが、あなたの IP アドレスを記録・保存・利用することはなく、上記の匿名カウントと結び付けることもありません。

3. アカウント登録

本アプリはアカウント登録機能を持ちません。メールアドレス・電話番号・氏名などの登録は不要です。お子さま (プロフィール) の名前は端末内に保存されるラベルであり、外部送信はされません。

4. ユーザートラッキング

本アプリは Google Analytics や Facebook SDK 等の第三者アナリティクス・トラッキング SDK を組み込んでいません。広告も表示しません。セクション2の匿名カウントは開発者自身のサーバーにのみ送られ、個人と結び付かず、他社のアプリやウェブサイトをまたいであなたを追跡する用途には使いません。そのため App Tracking Transparency (ATT) の対象となるトラッキングには該当せず、ATT のリクエストも行いません。

5. 位置情報の使用

天気予報の取得のため、初回のみ位置情報の使用許可をお願いします (オプション)。位置情報は Apple WeatherKit へのリクエストにのみ使用され、開発者を含む第三者には共有されません。位置情報の使用を拒否した場合は、東京の天気を既定値として表示します。

6. 天気 API への通信

天気予報の取得には Apple WeatherKit (apple.com) を使用します。リクエストには緯度経度のみが含まれ、ユーザー識別子・端末識別子などの個人情報は送信されません。取得した天気データはお使いの端末内のみに保存されます。

7. カレンダーへのアクセス

学習スケジュールへの予定取り込み機能を使用する場合、iOS のカレンダー API (EventKit) へのアクセス許可をお願いします (オプション)。アクセスが許可されると、ユーザーが選択したイベントを 端末内でローカルに 学習スケジュールに変換します。カレンダーの内容が開発者を含む第三者に送信されることは一切ありません。

8. アプリ連携・ウィジェット

ホーム画面ウィジェット及びロック画面 Live Activity に学習データのスナップショットを表示するため、iOS の App Group 機能を使用してアプリ本体とウィジェット間で表示用データを共有しています。これらは お使いの端末内のみ のデータ共有であり、外部送信は行われません。

9. アプリ内課金 (Strideline Pro)

本アプリは Strideline Pro (買い切り型 IAP) を提供しています。購入処理は Apple の StoreKit を介して行われ、Apple のプライバシーポリシーが適用されます。開発者は決済情報を一切受け取らず、ユーザーの購入の事実 (isProUnlocked フラグ) のみを Apple App Store から取得します。

10. お子さまのプライバシー

本アプリは中学受験生を含む 13 歳未満のお子さまの利用を想定しています。以下の理由により、お子さまから個人情報を収集することはありません:

  • アカウント登録機能なし
  • 学習データはすべて端末内のみに保存
  • 位置情報・カレンダー連携はすべてオプション (使わなくても基本機能はすべて使えます)
  • 第三者の広告・トラッキング SDK ゼロ
  • セクション2の匿名利用統計は識別子を持たない合計値 (集計) のみで、特定のお子さまを識別したり、時系列で追跡したり、プロファイルを作ったりすることは構造的にできず、個人 (お子さまを含む) を特定する情報を一切含みません

11. ポリシーの変更

本ポリシーは変更される場合があります。重要な変更はアプリ内およびこのページでお知らせします。

12. 連絡先

本ポリシーに関するご質問は trim.hoist.6b@icloud.com までお寄せください。

Strideline — Privacy Policy

Last updated: 2026-07-12 (v1.1)

What changed in v1.1: To improve the App, we added the sending of anonymous usage counts (see Section 2 below). We count how many times the app is launched, which features are used, and views/purchases of the paid upgrade (Strideline Pro) — all as anonymous totals. Because the App holds no identifier of any kind, it cannot identify a specific child, track an individual over time, or build a profile. No name, email, device identifier, location, or study content is included. We include this note to be transparent about the change.

This Privacy Policy explains how Strideline (the "App") handles user information.

1. Data Collection

All of your study data and personal data — study schedules, planned blocks, recorded sessions, countdowns, and materials — are stored only on your device via iOS-native SwiftData and are never sent to the developer's servers. The only thing that leaves your device is the anonymous usage statistics (identity-free event counts) described in Section 2.

2. Anonymous Usage Statistics

To make the App better, it sends anonymous usage counts to the developer's own server (collect.appline.app). Three kinds of things are counted, all as totals (aggregates) only:

  • How many times the app is launched (a rough measure of how much it is used)
  • Which features / screens are used (e.g. opening the calendar, stats, or countdown; starting the study timer; adding a material; importing from the calendar — so we can find features that are unused and improve them)
  • Actions around the paid upgrade (Strideline Pro) (e.g. Pro screen shown, purchase button tapped, purchase completed, purchase restored)

What is sent (only this): a fixed, predefined event name plus the app version number (e.g. 1.1). Nothing else.

What is never sent: no name, email, account information, device identifier (IDFA / IDFV), advertising ID, location, study content, or any other information that could identify a person.

No individual or child can be identified or tracked: the App assigns no persistent identifier to a device or a child (no device ID, no session ID). So all that is sent is "how many times, in total, an action happened" — there is no key to join these counts on, which makes it structurally impossible to identify a specific user or child, follow the same person over time, or build a profile. Per-user metrics such as the number of active users or retention are also not obtainable this way (we learn those only from the anonymous data aggregated by Apple's App Store Connect).

Where it goes: only to a server operated by the developer (on Cloudflare). It is never shared with any third party such as Google, Firebase, or Meta. The request necessarily transits the developer's server infrastructure (Cloudflare) at the network level, but your IP address is not logged, stored, or used, and is never associated with the anonymous counts above.

3. Account Registration

The App has no account registration feature. No email address, phone number, or personal identifier is required. Profile names (e.g. for siblings) are stored as on-device labels only and are never transmitted externally.

4. User Tracking

The App does not embed any third-party analytics or tracking SDKs (Google Analytics, Facebook SDK, etc.). No advertisements are displayed. The anonymous counts in Section 2 are sent only to the developer's own server, are not linked to your identity, and are not used to track you across other companies' apps or websites. They therefore do not constitute tracking under App Tracking Transparency (ATT), and no ATT prompt is issued.

5. Use of Location

To provide weather forecasts, the App requests location permission once (optional). Location is used solely for requests to Apple WeatherKit and is not shared with anyone, including the developer. If location access is denied, weather for Tokyo is displayed as a default.

6. Communication with Weather API

For weather forecasts, the App uses Apple WeatherKit (apple.com). Requests include only latitude/longitude coordinates, never any user or device identifier. Retrieved weather data is stored only on your device.

7. Calendar Access

If you use the schedule-import feature, the App will request access to the iOS Calendar API (EventKit) (optional). When granted, events you select are converted to study blocks locally on your device. Calendar contents are never transmitted to the developer or any third party.

8. App Integrations & Widgets

To display study snapshots on Home Screen widgets and Lock Screen Live Activities, the App uses iOS App Groups to share display data between the main app and the widget extension. This is on-device data sharing only; nothing is transmitted externally.

9. In-App Purchase (Strideline Pro)

The App offers Strideline Pro, a one-time non-consumable IAP. Purchase processing is handled by Apple StoreKit and is governed by Apple's Privacy Policy. The developer never receives payment details and only learns the purchase fact (isProUnlocked) from the Apple App Store.

10. Children's Privacy

The App is intended for students preparing for entrance exams, including those under 13. The following measures ensure no personal data is collected from children:

  • No account registration
  • All study data is stored only on the device
  • Location access and Calendar integration are entirely optional (core features work without them)
  • Zero third-party advertising or tracking SDKs
  • The anonymous usage statistics in Section 2 are identifier-free totals (aggregates) only; they make it structurally impossible to identify, track over time, or profile a specific child, and contain nothing that identifies any person, including a child

11. Changes to This Policy

This Policy may be updated. Material changes will be announced in-app and on this page.

12. Contact

If you have any questions about this Privacy Policy, please contact us at trim.hoist.6b@icloud.com.
