ホーム サポート 利用規約

Fineline（以下「本アプリ」）は幾何学模様を制作するためのツールです。アカウント登録・ログイン・SNS 的な機能はありません。

1. 作った柄は端末内に保存されます

保存した柄・その名前・パレット・手描きの線は、すべて端末内にのみ保存されます。サーバーにアップロードされることはなく、開発者が閲覧することはできません。アプリを削除するとこれらのデータも削除されます。

2. 匿名の利用統計

本アプリの改善のため、匿名の操作カウントを開発者自身のサーバー（collect.appline.app）に送信します。記録されるのは合計値（集計）のみで、内容は「どの機能が使われたか（書き出した／柄を保存した／手描きを編集画面に取り込んだ）」と「有料版の案内・購入まわりの操作（Pro画面の表示・購入ボタン・購入完了・復元）」です。

送信するのはこれだけです: あらかじめ決められた固定のイベント名 + アプリのバージョン番号（例: 1.0）。

送信しないもの: 氏名・メールアドレス・アカウント情報・端末識別子（IDFA / IDFV）・広告 ID・位置情報、そしてあなたが作った柄や手描きのデータ。これらは一切送信しません。

個人を特定・追跡することはできません: 本アプリは永続的な識別子を一切割り当てません（端末 ID・セッション ID を持ちません）。したがってサーバーに残るのは「ある操作が合計で何回起きたか」だけで、それらを結び付ける手がかりが存在せず、特定の利用者を識別したり、同一人物を時系列で追いかけたり、プロファイルを作ったりすることは構造的に不可能です。アクティブユーザー数や継続率のような個人単位の統計もこの仕組みでは取得できません（それらは Apple の App Store Connect が集計する匿名データからのみ把握します）。

送信先: 開発者が管理するサーバー（Cloudflare 上）のみです。Google・Firebase・Meta などの第三者に渡すことはありません。通信は Cloudflare を経由しますが、あなたの IP アドレスを記録・保存・利用することはなく、上記の匿名カウントと結び付けることもありません。

3. 広告・トラッキングはありません

本アプリは広告 SDK・第三者製の解析 SDK を一切含みません。アプリや Web サイトを横断した追跡は行わないため、トラッキング許可のダイアログも表示しません。

4. アプリ内課金

Fineline Pro は Apple の App Store を通じて処理される買い切りのアプリ内課金です。支払い情報は Apple がすべて処理し、開発者がカード情報を受け取ったり保存したりすることはありません。購入済みかどうかの判定は、端末上で App Store のレシートを参照して行われます。

5. 共有・書き出し

柄を書き出すと、ファイルは端末上で生成され iOS 標準の共有シートに渡されます。その先（ファイル・写真・メール・他のアプリ）を決めるのはあなたであり、本アプリが独自にどこかへ送信することはありません。

6. お子さまの利用

本アプリは、お子さまを含むいかなる利用者からも個人情報を収集しません。識別子を割り当てないため、年齢にかかわらず利用者のプロファイルを作ることはできません。

7. データの削除

あなたの柄はすべて端末内に保存されているため、アプリを削除すれば消去されます。第2節の匿名カウントには個人を特定する情報が含まれないため、個人単位で特定して削除することは構造上できません。

8. 本ポリシーの変更

本ポリシーを変更する場合は、更新版を本ページに掲載し、冒頭の更新日を改めます。
