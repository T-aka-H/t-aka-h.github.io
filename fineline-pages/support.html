ホーム プライバシーポリシー 利用規約

Fineline は、数学的に正しい対称性で幾何学模様を生成し、入稿に使えるファイルとして書き出すアプリです。よくあるご質問をまとめました。

使いはじめ

Studio が編集画面です。左のレールで形、右のレールで対称を選び、下のパネルで大きさ・リピート・色を調整します。Shuffle はワンタップで柄をまるごと生成します。Draw は 1 マスの中に手描きすると、選んだ対称で複製されます。Library は保存した柄の一覧です。

縦横比が動かないのはなぜ？

正方系（p4 / p4m / p4g）と六角系（p3 / p3m1 / p31m / p6 / p6m）では、セルの縦横比が対称性そのものによって固定されています。変えると繰り返しが成立しなくなるため、本アプリではその旨を表示してスライダーを出しません。長方系（p1 / p2 / pm / pg / cm / pmm / pmg / pgg / cmm）を選ぶと調整できるようになります。

柄はシームレスに連続しますか？

はい。すべての柄は継ぎ目なく平面を埋めるリピート単位として生成され、書き出されるのもその単位です。「リピート」タブの「リピート単位を表示」で境界を確認できます。

入稿用の書き出し

拡大しても劣化しないベクターは SVG または PDF、画像は PNG / JPEG を選びます。サイズは実寸（cm）と解像度（dpi）で指定するため、10cm・300dpi なら印刷所が想定するピクセル数で出力されます。生産前に寸法・色・解像度を印刷所とご確認ください。

Fineline Pro は自動更新のない買い切りです。無料・有料いずれも書き出しに透かしは入りません。商用利用の範囲は利用規約をご覧ください。

購入したのに Pro になりません

アプリ内の Settings を開き「購入を復元」をタップしてください。App Store のレシートを読み直します。購入時と異なる Apple ID でサインインしている場合は、購入した Apple ID に切り替えてからお試しください。

保存した柄はどこにありますか？

保存した端末の Library タブにあります。端末内に保存され、端末間で同期はされないため、アプリを削除すると消えます。残しておきたいものは書き出してください。

保存した柄の名前を変える

柄の名前は保存した日付が既定です。Library で長押しして「名前を変更」を選んでください。
