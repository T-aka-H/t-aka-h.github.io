ヨミオケ — プライバシーポリシー

ホーム サポート

最終更新: 2026年7月28日

本ポリシーは、ヨミオケ（英語名: Read-OK、以下「本アプリ」）における情報の取り扱いを説明します。

1. 収集する情報

本アプリは個人を特定する情報を収集・保存しません。アカウント登録は不要で、第三者の分析（アナリティクス）や広告の SDK は含まれていません。端末外へ送信されるのは、セクション2で説明する匿名の利用統計（個人と結び付かない操作カウント）と、あなたが Game Center にサインインしている場合のスコア送信（セクション6）のみです。

以下のデータはお使いの端末上にのみ保存されます。

  • 測定結果のスコア・読み取りメモ・（任意で）波形の要約
  • 個人ベストや設定（録音前確認の表示など）
  • Pro 購入済みかどうかの事実（StoreKit 経由）
  • 持ち込み文の測定履歴（Pro。本文は端末内のみ）

2. 匿名の利用統計

本アプリをよりよくするため、匿名の操作カウントを開発者自身のサーバー（collect.appline.app、Cloudflare 上）に送信します。数えるのは次の種類で、いずれも合計値（集計）のみです:

  • アプリが起動された回数
  • 収録文学の課題が測定された回数（あらかじめ決められた課題 ID のみ。持ち込み文の ID や本文は送りません）
  • ランキング画面の表示
  • ヨミオケ Pro の案内・購入まわり（表示・購入タップ・購入完了・復元）

送信する内容（これだけです）: あらかじめ決められた固定のイベント名・課題 ID ＋ アプリのバージョン番号のみ。

送信しないもの: 氏名・メールアドレス・端末識別子（IDFA / IDFV など）・広告 ID・位置情報・朗読の音声・持ち込み文の本文・その他あらゆる個人を特定できる情報。

個人を特定・追跡することはできません: 本アプリは端末やユーザーに永続的な識別子を一切割り当てません。送られるのは「ある操作が合計で何回起きたか」だけで、特定の個人を識別したり、同一人物を時系列で追いかけたり、プロファイルを作ったりすることは構造的に不可能です。

送信先: 開発者自身が管理するサーバーのみです。Google・Firebase・Meta などの第三者には渡しません。あなたの IP アドレスを記録・保存・利用することはなく、匿名カウントと結び付けることもありません。

ホームの「最近人気の朗読」は、上記の課題測定カウントの公開集計（課題 ID ごとの合計のみ）を同じサーバーから取得して表示します。

3. 端末内での処理

マイクで取り込んだ音声の分析（存在感・抑揚・間・強弱・語尾など）は、すべてお使いの端末内で実行されます。録音データは分析後に端末上の一時ファイルから削除され、開発者のサーバーに送信されることはありません。

4. 端末の権限

  • マイク — 朗読の声の表現を端末内で測定するために使用します。録音は外部へ送信されません。

5. ネットワーク通信

セクション2の匿名カウント送信・人気集計の取得のほか、Game Center（セクション6）やアプリ内課金（セクション7）で Apple のサービスと通信することがあります。朗読の音声や持ち込み文の本文を開発者のサーバーへ送ることはありません。

6. Game Center

あなたが Game Center にサインインしている場合、収録文学の測定スコア（点数のみ。音声は含みません）を Apple の Game Center リーダーボードに送信することがあります。持ち込み文（Pro）のスコアはリーダーボードに入りません。Game Center の扱いは Apple のプライバシーポリシーが適用されます。

7. アプリ内課金（ヨミオケ Pro）

本アプリは、自分の文を貼って測定するための買い切り型アプリ内課金「ヨミオケ Pro」を提供しています。収録文学の測定は無料のままです。購入処理はすべて Apple の StoreKit を通じて行われ、Apple のプライバシーポリシーが適用されます。開発者がクレジットカード番号などの決済情報を受け取ることはなく、App Store から購入済みかどうかの事実のみを取得します。

8. ユーザートラッキング

本アプリは第三者アナリティクス・トラッキング SDK を組み込んでいません。広告も表示しません。セクション2の匿名カウントは開発者自身のサーバーにのみ送られ、個人と結び付かず、他社のアプリやウェブサイトをまたいで追跡する用途には使いません。そのため App Tracking Transparency (ATT) の対象となるトラッキングには該当せず、ATT のリクエストも行いません。

9. 子どものプライバシー

本アプリは 4+ 向けです。13 歳未満から意図的に個人情報を収集することはありません。セクション2の匿名利用統計は識別子を持たない合計値のみで、個人（子どもを含む）を特定する情報を一切含みません。

10. 改定について

本ポリシーを更新する場合は、本ページの「最終更新」を改訂します。

11. お問い合わせ

ご質問は、App Store のアプリページに記載のお問い合わせ方法をご利用ください。
